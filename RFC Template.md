# Motivation

# Detailed Design

This is the core of the RFC. Explain the design in enough detail for somebody to understand the problem, and for somebody familiar with the code practices to implement. This should get into specifies and corner-cases, and include examples of how the feature is used. You can use wireframe, activity flow, system design, pseudo code, anything diagrams you need to. Make it concise

---

# Drawbacks

---

# Alternatives

---
